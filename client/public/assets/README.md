# Assets Directory Structure for SIH 2026

This directory provides asset locations for the K J Somaiya SIH 2026 Internal Hackathon platform:

- `branding/`: Official institutional logos
  - `kj-somaiya-logo.svg` / `kj-somaiya-logo.png`
  - `sih-2026-logo.svg` / `sih-2026-logo.png`
- `images/`: High-resolution event photographs, campus banners, jury photos
- `gifs/`: Animated reaction or event celebration GIFs
- `3d/`: 3D models (`.glb`, `.gltf`, `.bin`, textures) for Three.js / React Three Fiber
